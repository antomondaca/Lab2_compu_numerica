Descripción del proyecto

Este repositorio contiene el desarrollo completo de nuestra evaluación 2 de computación numérica, cuyo objetivo es implementar y comparar seis métodos de búsqueda de raíces, los cuales los metodos son los siguientes:
Bisección
Falsa Posición
Secante
Newton-Raphson
Newton-Raphson Mejorado

Con estos métodos analizaremos distintas funciones(polinómicas, logarítimicas, exponenciales, trigonométricas y mixtas), incluyendo el ánalisis crítico de una función con raíz doble que solo toca el eje x.
